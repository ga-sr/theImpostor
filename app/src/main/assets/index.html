Como jogar

  1. Adicione os jogadores. Mínimo de 3.
  2. Passe o celular. Cada um segura a carta e vê a palavra secreta.
  3. O impostor não recebe a palavra. Ele vê "VOCÊ É O IMPOSTOR".
  4. Em ordem, cada um diz uma palavra relacionada ao tema.
  5. Depois do debate, todos votam em quem acham que é o impostor.
  6. Se o impostor for expulso, ele ainda tem uma chance: acertar a palavra secreta para virar o jogo.

Dicas: cada palavra tem 3 dicas. Com a opção ligada, cada impostor recebe uma dica sorteada, diferente das dos outros impostores.

Pontos: grupo ganha 1 ponto cada se pegar o impostor. Impostor ganha 2 se escapar ou acertar a palavra.


Minhas palavras

Uma palavra por linha. Para dar dicas ao impostor, use dois pontos e vírgulas: Palavra: dica1, dica2, dica3
